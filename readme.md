# Speidermerker - Vestbyspeiderne

En enkel nettside for registrering og oppfølging av fordypningsmerker og programmerker for stifinnere og vandrere i Vestbyspeiderne.
Nettsiden er basert på merkeprogrammet til Norges Speiderforbund og er utviklet som et hjelpemiddel for speidere og foresatte for å få oversikt over progresjon og oppnådde merker.

En enkel webapplikasjon for registrering og oppfølging av:
- Fordypningsmerker
- Programmerker

for

- Stifinnere (10-12 år)
- Vandrere (13-16 år)

i Norges Speiderforbund.

## Teknologi

- HTML
- JavaScript (innebygd i HTML)
- GitHub Pages

Nettsiden består av én enkelt HTML-fil og krever ingen server, database eller installasjon.

## Hosting

Nettsiden publiseres via GitHub Pages.

## Opphavsrett

Alt innhold og kildekode i dette repositoriet tilhører Simen Nørstebø og Vestbyspeiderne dersom ikke annet er angitt.
Ingen lisens er gitt for gjenbruk, distribusjon eller videreutvikling av kildekoden uten uttrykkelig tillatelse fra opphavspersonen.

## Ansvarsfraskrivelse

Dette er et frivillig utviklet hjelpemiddel for bruk i speidergruppen og er ikke et offisielt system fra Norges Speiderforbund.

## Personvern

Løsningen lagrer ingen personopplysninger på server.
Eventuelle data lagres lokalt i nettleseren.
